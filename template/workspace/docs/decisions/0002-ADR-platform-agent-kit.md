# ADR-0002: агенты, скиллы и правила через multi-agent-kit

## Контекст

Проект открывают в Cursor, Claude Code и Codex. Описания агентов, скиллов, команд, правил и
MCP-серверов должны быть одинаковыми во всех клиентах и обновляться из одного источника, а общие
скиллы — переиспользоваться между проектами.

## Решение

1. Платформенные каталоги `.cursor/`, `.claude/`, `.codex/`, `.agents/`, корневой `.mcp.json` и
   управляемый блок `AGENTS.md` генерирует `multi-agent-kit` по `multi-agent-kit.json`.
2. Общие паки приходят из пакета `multi-agent-kit` (dev-зависимость) и, при необходимости, из
   приватных источников. Своё для проекта — локальный слой `workspace/agent-kit/`, он побеждает паки.
3. Сгенерированные файлы коммитятся. Файлы из приватных источников в git не попадают.
4. Процесс решений — раздел «Процесс RFC, ADR и OPS» в `AGENTS.md`; номер и индекс выделяет
   `npx multi-agent-kit decisions`.
5. Значения окружения (хост, домен, БД) — `vars` в `multi-agent-kit.json`. Секреты туда не пишутся.

## Последствия

После правки исходников запускается `npm run agents:sync`, в CI — `npm run agents:check`. Правки
сгенерированных файлов переносятся в источник командой `adopt`. Обновление общих паков — смена версии
`multi-agent-kit` в `package.json`.
