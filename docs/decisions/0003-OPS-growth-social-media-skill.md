# OPS-0003: скилл `social-media-and-personal-brand` в паке `growth`

Продолжение и результаты следующего прохода: [OPS-0004](0004-OPS-growth-social-media-review.md).

Рабочий журнал, чтобы продолжить работу над скиллом с того места, где она остановилась.

## Задача

Публичный скилл с ветвящейся структурой (лаконичный `SKILL.md` + `references/`) по медийной активности
в соцсетях для основателя, эксперта, стартапа, цифрового продукта и SaaS: личный бренд, бренд бизнеса,
площадки (видео и текст), написание коротких постов и лонгридов, запуски, комьюнити, метрики, право РФ,
тренды, кейсы, шаблоны. Скилл должен отвечать на три вопроса: как продвинуть продукт в РФ и/или в мире,
как построить стратегию личного бренда, как двигаться по ней тактически. Опорная книга пользователя:
Игорь Манн «Номер 1» (сокращённое издание, 43 стр.).
