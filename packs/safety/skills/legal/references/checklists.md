# Чеклисты

Готовые списки для девяти ситуаций. Каждый пункт помечен доменом, чтобы при «нет» открыть нужный файл. Чеклист — страховка от забытого, не замена карты данных и оснований.

## 1. RFC / ADR новой фичи

**Рамка (L0)**
- [ ] Названы юрисдикция и роль (оператор / обработчик / посредник / ОРИ / продавец).
- [ ] Составлена карта данных: поле → основание → документ → хранилище → круг → срок.
- [ ] Составлены карты сообщений, чужого и денег.

**Персональные данные (L1)**
- [ ] Для каждого поля — основание из ст. 6; согласие только там, где не подходит договор/закон/интерес.
- [ ] Специальные категории и биометрия исключены или получено письменное согласие с ПЭП.
- [ ] Круг видящих определён; при неопределённом — согласие на распространение.
- [ ] Удаление реализовано реально: 30 дней, бэкапы по сроку ротации.
- [ ] Новые цели/категории → обновление уведомления РКН и политики.
- [ ] Дети: 18+ или режим для несовершеннолетних.

**Подрядчики и трансграница (L2)**
- [ ] Перечислены все, кто увидит данные; у каждого поручение.
- [ ] Первая запись — в РФ; за рубеж — только обезличенное или с уведомлением РКН.
- [ ] Хостинг в реестре РКН.

**Информационное право (L3)**
- [ ] Способы входа — только российские по ст. 8 ч. 10.
- [ ] Алгоритмическая выдача → уведомление и правила рекомендательных технологий.
- [ ] Нет обмена сообщениями между пользователями, либо оценён статус ОРИ.
- [ ] Пользовательский контент: правила, жалобы, удаление в 24 часа, посредничество.

**Договоры (L4)**
- [ ] Фича описана в соглашении; версия и дата; журнал акцепта.
- [ ] Раздел о ПЭП покрывает новые действия (согласия, офферы).
- [ ] Нет условий, ущемляющих потребителя.
- [ ] Платное: цена, чек, автопродление с явным согласием, отмена в один шаг.

**Интеллектуальная собственность (L5)**
- [ ] Новые зависимости проверены по лицензиям; атрибуция.
- [ ] Чужие дизайн/шрифты/картинки — с документом.
- [ ] Код пишут люди с оформленными правами.
- [ ] Контент пользователей — лицензия в соглашении.

**Маркетинг (L6)**
- [ ] Каждое сообщение классифицировано: сервисное или реклама.
- [ ] Реклама — отдельное согласие, отписка, журнал.
- [ ] Платные размещения — erid и ЕРИР.

**Деньги (L7)**
- [ ] Кто получает, кто бьёт чек, нет посредничества в чужих платежах.

**Международное (L8)**
- [ ] Нет признаков таргетинга на ЕС/США/СНГ, либо выполнен чеклист новой страны.

**ИИ (L9)**
- [ ] Для каждой функции модели — режим из таблицы L9.
- [ ] Решения, затрагивающие права, — с человеком и обжалованием.
- [ ] Тексты в модель — обезличены или провайдер в РФ.
- [ ] Дисклеймер и границы тем.

**Операции (L10)**
- [ ] Новые журналы (согласия, акцепты, выдачи) заведены.
- [ ] Шаблон уведомления об утечке покрывает новые данные.

**Итог**
- [ ] Раздел «Право» в RFC написан по шаблону; риски с владельцами и сроками; список для юриста.

## 2. Проверка OPS (выкладка)

- [ ] База и бэкапы физически в РФ; адрес соответствует уведомлению РКН (L1, L2).
- [ ] Новые подрядчики (хостинг, CDN, почта, LLM, трекер) — поручение, страна, запись в политике (L2).
- [ ] Нужно ли обновить уведомление РКН (цели, категории, трансграница, адрес) — подано до выкладки (L1).
- [ ] Обновлены политика, соглашение, правила алгоритмов: версия, дата, уведомление пользователей, журнал (L4, L3).
- [ ] Изменились ли сроки хранения/удаления; скрипты уничтожения работают (L1).
- [ ] Новые рассылки — согласия и отписка (L6).
- [ ] Новые зависимости — лицензии и атрибуция (L5).
- [ ] Логи и трекеры не пишут ПДн сверх политики (L1).
- [ ] Возможность ответить субъекту и выдать данные по запросу сохранена (L10).
- [ ] Откат не ломает журналы согласий и акцептов (L4).

## 3. Запуск сервиса (минимальный правовой пакет)

- [ ] ИП/ООО, ОКВЭД, реквизиты на сайте (L7, L4).
- [ ] Ответственный за ПДн назначен приказом (L1).
- [ ] Уведомление РКН об обработке подано; при трансгранице — отдельное (L1, L2).
- [ ] Политика обработки ПДн опубликована; ссылка на формах (L1).
- [ ] Перечень ПДн, реестр обработки, акт УЗ, оценка вреда, порядок уничтожения — есть (L1).
- [ ] Поручения со всеми подрядчиками; хостинг в реестре (L2).
- [ ] Пользовательское соглашение с ПЭП, версия, журнал акцепта (L4).
- [ ] Согласия отдельными документами там, где нужны; журнал (L1, L6).
- [ ] Правила сообщества и процедура жалоб; контакт для правообладателей (L3, L5).
- [ ] Правила рекомендательных технологий и уведомление, если есть алгоритм (L3, L9).
- [ ] Вход только российскими способами (L3).
- [ ] 18+ и подтверждение возраста (L3, L1).
- [ ] Права на код, бренд, домен — на компании; лицензии зависимостей проверены (L5).
- [ ] Шаблон уведомления об утечке, план реагирования, адрес для запросов, журналы (L10).
- [ ] security.txt (L10).
- [ ] Если платежи: провайдер, чеки, подписки по правилам (L7, L4).

## 6. Новая рассылка или канал уведомлений

- [ ] Классификация: сервисное или реклама (L6).
- [ ] Если реклама: отдельное согласие получено до отправки; журнал; отписка в каждом сообщении (L6).
- [ ] Канал: провайдер в РФ или поручение + трансграница (L2).
- [ ] Текст без «лучший/№1», обещаний результата, запрещённых тем (L6).
- [ ] Для платных размещений — erid, ОРД, ЕРИР (L6).
- [ ] Для звонков — маркировка, согласие (L6).
- [ ] Для push — настройка отключения (L6).
- [ ] Шаблоны соответствуют требованиям почтовых провайдеров (L6).

## 9. Аудит существующего сервиса (первый проход за день)

1. **Снаружи**: политика на сайте и ссылки на формах; реквизиты; реестр операторов РКН (есть ли запись и совпадают ли цели); способы входа; уведомление о рекомендациях и правила; cookie-уведомление; правила сообщества и контакт для жалоб; security.txt (L1, L3, L10).
2. **Документы**: приказ об ответственном; перечень и реестр обработки; акт УЗ; оценка вреда; соглашение с версиями и журналом; согласия отдельными документами; поручения с подрядчиками; уведомление о трансгранице; методика обезличивания (L1, L2, L4).
3. **Инфраструктура**: где база, бэкапы, трекеры, аналитика, LLM, почта; страна каждого; реестр хостинга (L2).
4. **Данные**: какие поля собираются и зачем; специальные категории в текстах; дети; удаление реально ли; сроки (L1).
5. **Сообщения**: что отправляется, классификация, согласия, отписка (L6).
6. **ИС**: кто писал код и по каким документам; лицензии зависимостей; знак и домен (L5).
7. **Деньги**: провайдер, чеки, подписки, посредничество (L7).
8. **Процессы**: куда приходят запросы, журналы, шаблоны, кто отвечает, сроки (L10).
9. **Международное**: признаки таргетинга (L8).
10. **ИИ**: таблица L9 (L9).
Выход: таблица рисков (вероятность × санкция), топ-5 «закрыть на этой неделе», план на квартал, список вопросов юристу.
