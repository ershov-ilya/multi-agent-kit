# Изменение возможностей агентов

Скиллы, агенты, команды, правила и MCP-серверы этого проекта собирает `multi-agent-kit`
по `multi-agent-kit.json`. Файлы в `.cursor/`, `.claude/`, `.codex/` и `.agents/` с пометкой
`Generated by multi-agent-kit` производные: вручную их не правь.

Где менять:

- своё для проекта — в локальном слое `{{mak.local}}/` (skills, agents, commands, rules, context, mcp);
- общее для многих проектов — в источнике, откуда пришёл файл: он указан в пометке `Source:`
  первой строкой сгенерированного файла. Подключить или отключить пак — в `multi-agent-kit.json`.

После изменения выполни `{{mak.cli}} sync`, затем `{{mak.cli}} sync --check`. Сообщи, какие
платформенные файлы обновились. Если правка уже сделана прямо в сгенерированном файле, перенеси её
в источник командой `{{mak.cli}} adopt <файл>` и только потом запускай `sync`.

Не добавляй в исходники и сгенерированные файлы секреты, токены, ключи и реальные пароли.
Файлы из приватных источников не коммить: `sync` исключает их из git сам.
