# Российский рынок: специфики привычек 2026

Файл для продуктов с российской аудиторией. При переносе скилла на другой рынок его можно не читать или заменить аналогом. Цифры — ориентир, источники и год указаны; правовая сторона — в скилле `legal`.

## Карта специфик

| Область | Что наблюдаем (2025–2026) | Что это значит для продукта |
|---|---|---|
| **Мессенджеры как центр** | Mediascope, февраль 2026: месячная аудитория Telegram ≈ 95,7 млн, WhatsApp ≈ 80,3 млн (падает после ограничений), Max ≈ 77,6 млн (растёт, предустановлен, госсервисы). Весной–летом 2026 — замедления Telegram, частичные блокировки; половина аудитории не планирует переходить в Max | Канал уведомлений и вход — через мессенджер, но не через один: Telegram-бот + email + Max по готовности; не строить продукт на доступности одного мессенджера; web как независимая база |
| **Устройства** | StatCounter 2026: Android ≈ 67 % мобильного трафика, iOS ≈ 33 % (доля iOS снизилась за 2026); среди владельцев в городах-миллионниках iPhone до ≈ 45–50 % (2ГИС 2025); продажи по штукам — Xiaomi, Samsung, realme, Tecno; средний чек снижается | Проектировать под средний Android (6–8 ГБ, бюджетный чип) и iPhone 11–14; тест на обеих; лёгкость важнее анимаций |
| **Мобильный интернет** | Минцифры 2026: мобильный трафик снижается, Wi-Fi растёт (ограничения мобильного интернета в ряде регионов, «белые списки»); нестабильность сети как норма в 2025–2026 | Офлайн-терпимость, лёгкие экраны, работа через Wi-Fi и при ограничениях; не зависеть от зарубежных CDN и шрифтов (могут не грузиться) |
| **Сторы и платежи** | Apple Pay / Google Pay недоступны с 2022; часть приложений удалена из сторов; RuStore предустановлен на Android; оплата — СБП, карты Mir, Яндекс Пэй, T-Pay; рассрочки популярны | Web/PWA как основной канал; СБП первым; нативное — с RuStore и прямым APK; подписки через провайдера, не через стор |
| **Идентификация** | Телефон — главный идентификатор (банки, Госуслуги, маркетплейсы); email у молодых используется реже; Госуслуги (ЕСИА) — доверенный вход для серьёзных сервисов; вход через иностранные сервисы запрещён (см. `legal` L3) | Вход по телефону или своему коду на email/в мессенджер; VK ID/Яндекс ID как опции; предупреждать «не звоним, не показываем» при запросе телефона |
| **Маркетплейсы как норма UX** | Ozon, Wildberries, Яндекс Маркет формируют ожидания: фильтры-чипсы, рейтинги, отзывы с фото, статусы заказа, «пункт выдачи», быстрые ответы поддержки | Статусы и сроки показывать как «статус заказа»; отзывы и рейтинг там, где уместно; чипсы фильтров |
| **Банковские приложения как эталон** | Т-Банк, Сбер, Альфа — высокий стандарт скорости, чата поддержки, персональных предложений, вход по биометрии/коду | Пользователи ждут такой же скорости и ясности статусов; чат поддержки с быстрым ответом |
| **Голосовые сообщения** | Распространены среди молодых и занятых; старшие и B2B — раздражение | Если принимаем голос — транскрипция; не основной канал |
| **Обращение и имена** | «Вы» по умолчанию; «ты» — в молодёжных и внутренних сообществах; отчество — в официальных и для старших; имя одним словом — норма для сервисов | Единый тон; одно поле «как к вам обращаться»; без обязательного отчества, если не требует закон |
| **Отношение к данным** | Высокая осведомлённость об утечках (громкие случаи 2022–2025), скепсис к запросу лишнего, но готовность делиться с «понятным» сервисом; спам-звонки — массовая боль | Объяснять каждый запрос данных; «не звоним»; минимизация; видимая кнопка удаления |
| **Отношение к ИИ** | Широкое использование (Алиса, GigaChat, YandexGPT, ChatGPT через обходы); осторожное доверие; ИИ-колл-центры раздражают | Ассистент как помощник с человеком рядом; без имитации человека; называть по пользе |
| **Госуслуги и официальность** | Привычка к электронным документам, кодам, уведомлениям от государства; доверие к «официальному» дизайну у старших | Для серьёзных действий — ясные статусы и подтверждения, как в Госуслугах; не копировать визуально государственный стиль |
| **Сообщества** | Жизнь в закрытых чатах (дом, школа, работа, хобби); доверие внутри круга выше; «свой человек» ценится | Продукт внутри сообщества — сильная модель; показывать общность; инвайты через чаты |
| **Знакомства и контакты** | Усталость от приложений знакомств; возврат к знакомству через знакомых, мероприятия, сообщества; осторожность женщин | Запрос с целью, двойное согласие, закрытый круг, выход в мессенджер |
| **Время и ритм** | Пики активности: утро в транспорте (7–9), обед, вечер (20–23); выходные — дневные пики; часовые пояса от UTC+2 до UTC+12 | Тихие часы по поясу пользователя; дайджест вечером воскресенья или утром понедельника; уведомления в активные окна |
| **Локализация** | Русский без англицизмов для широкой аудитории; английские термины понятны в ИТ-сообществах; рубли, ДД.ММ.ГГГГ, +7, неделя с понедельника | Intl-форматирование, русская терминология продукта |
| **Поддержка** | Ожидают чат в продукте или в Telegram с ответом за минуты-часы; звонить не хотят; email — для документов | Чат поддержки (человек или ИИ с переходом к человеку), часы ответа указаны |
| **Старшая аудитория** | Активно в Telegram/WhatsApp/Max, Госуслугах, банках; боится ошибиться, читает медленно, любит явные кнопки | Крупный текст, явные глаголы, подтверждения, нет жестов как единственного пути |
| **Доверие к бренду** | Реквизиты, юрлицо, отзывы, «о нас», российский домен и хостинг — сигналы; анонимность настораживает | Реквизиты в футере, страница «о нас», понятная политика (см. `h7`, `legal`) |

## Чеклист для российского продукта

- [ ] Web-ссылка открывается без установки; OG-превью читаемо в Telegram/Max.
- [ ] Вход по телефону или своему коду; никаких Google/Apple Sign-in.
- [ ] Уведомления: выбор из Telegram-бот / email / (Max), push позже; тихие часы по поясу.
- [ ] Оплата: СБП первым, Mir, чек сразу.
- [ ] Первый экран < 1 с на среднем Android по нестабильной сети; шрифты и скрипты с российских или своих хостов.
- [ ] Тон «вы», одно поле имени, рубли и даты по-русски.
- [ ] Объяснение у каждого запроса данных; «не звоним».
- [ ] Чат поддержки с указанным временем ответа.
- [ ] Запасной канал на случай ограничений мессенджера.
- [ ] Правовые требования по `legal`: авторизация, рекомендательные технологии, ПДн.
