# H15. Платформы, устройства и конвенции

> Люди почти не ставят новые приложения, живут в браузере и мессенджере и ждут, что продукт ведёт себя по правилам платформы, на которой открыт. Для пилота это значит web или Mini App, а не нативное приложение; для любого продукта — системная «назад», системные шрифты и жесты платформы.

Источники: Comscore/Sensor Tower (средний пользователь ставит ~0–1 новых приложений в месяц; большинство времени — в 5 приложениях), data.ai, Google (PWA и добавление на экран), Telegram (Mini Apps: сотни миллионов пользователей, 2024–2026), StatCounter 2026 (РФ: Android ≈ 67 %, iOS ≈ 33 % мобильного трафика; мобильный трафик > 60 % веба), Apple HIG, Material 3, Android predictive back (14+), ограничения App Store/Google Play в РФ (платежи, удаление приложений), RuStore (с 2022, предустановка), Минцифры 2026 (мобильный трафик снижается, Wi-Fi растёт).

## Привычки

| Привычка | Что наблюдаем | Что это значит | Типичная ошибка |
|---|---|---|---|
| **Не ставят приложений** | Установка — барьер: место, доверие, стор; большинство новых приложений удаляют за неделю | Для пилота и редкого использования — web/PWA/Mini App; нативное — когда есть ежедневная привычка или нужны возможности устройства | Нативное приложение на старте |
| **Живут в мессенджере** | Telegram/Max как платформа: боты, Mini Apps, оплата, уведомления | Mini App или бот как вход и канал; авторизация через привычный контекст (с оговоркой `legal` L3) | Игнорировать мессенджер как платформу |
| **Ссылка должна открываться сразу** | Из чата — тап — продукт; без стора, без регистрации до ценности | Web-ссылка с OG-превью, deep link, мгновенная загрузка | Ссылка на стор |
| **Системная «назад» — закон Android** | Кнопка/жест назад ожидают на каждом экране; predictive back показывает, куда вернёт | Обработка назад в web (history) и Mini App (BackButton API); не выбрасывать | «Назад» закрывает всё |
| **iOS: свайп от края и таб-бар снизу** | Свайп назад, большие заголовки, шиты снизу | Соблюдать HIG; таб-бар, навигационный бар, модальные шиты | Android-паттерны на iOS |
| **Android: Material и системные элементы** | Material You, нижняя навигация, FAB уместен, системные диалоги | Material 3; динамические цвета — по желанию; жесты системы | iOS-шиты на Android |
| **Web-привычки** | Адресная строка, вкладки, «открыть в новой вкладке», Ctrl+F, закладки, печать | Настоящие ссылки, работающая история, состояние в URL, не ломать правый клик и выделение | SPA без URL состояний |
| **Добавить на экран — редко, но ценно** | PWA ставят, если продукт нужен регулярно и об этом попросили в момент ценности | Предложение «добавить на экран» после 2–3 сессий, своим баннером; manifest, иконки, офлайн-оболочка | Системный промпт сразу |
| **Обновления незаметны** | Web обновляется сам; приложения — пользователи откладывают | Web: версия без действий; приложение: совместимость API с отстающими версиями, принудительное обновление только критичное | Ломать старые клиенты |
| **Десктоп как второй экран** | Для «серьёзных» задач (длинный текст, сравнение, админка) открывают на десктопе | Адаптивность: десктоп не «растянутый мобильный»; клавиатура и широкие таблицы | Мобильный макет на 1440 px |
| **Планшеты и складные** | Небольшая, но заметная доля; ожидают двухпанельный интерфейс | Адаптивные брейкпоинты; не критично для пилота | Ломающийся макет |
| **Сторы в РФ** | Apple Pay/Google Pay недоступны, часть приложений удалена; RuStore как канал на Android; Huawei без GMS | Web/PWA как основной канал; для нативного — RuStore и прямой APK как резерв; оплата через СБП/провайдера | Расчёт на сторы и их платежи |
| **Камера, уведомления, геолокация** | Ждут нативных возможностей только там, где они дают ценность | Web даёт камеру, push (с ограничениями на iOS), гео; Mini App — часть; нативное — всё | Нативное «ради push» |
| **Системные шрифты и элементы** | Чужой шрифт и нестандартные контролы замедляют | Системные шрифты (SF, Roboto) или близкие; системные пикеры дат/файлов | Кастомный пикер даты |
| **Буфер обмена и шаринг** | Копировать текст, номер, ссылку; «поделиться» системным шитом | Копирование в один тап с подтверждением; Web Share API | Невыделяемый текст |
| **Низкий трафик и Wi-Fi** | Мобильный трафик экономят; видео по Wi-Fi | Лёгкие экраны; тяжёлое — по запросу | Автозагрузка тяжёлого |

## Выбор платформы для пилота (практика)

| Критерий | Web / PWA | Telegram Mini App | Нативное |
|---|---|---|---|
| Порог входа | Ссылка, ноль установки | Ссылка в чате, авторизация контекста | Стор, установка, разрешения |
| Уведомления | Email/Telegram-бот; web push ограничен на iOS | Через бота, высокий opt-in | Push с запросом разрешения |
| Возможности устройства | Камера, гео, базовое | Ограниченно | Всё |
| Обновления | Мгновенно | Мгновенно | Через стор, отстающие версии |
| Ограничения РФ | Нет | Зависимость от мессенджера, замедления 2026 | Сторы и платежи ограничены; RuStore |
| Право | Авторизация своя (`legal` L3) | Telegram Login — серая зона | То же, что web |
| Когда выбирать | Пилот, редкое использование, широкая аудитория | Аудитория уже в Telegram-сообществах | Ежедневная привычка, устройство нужно |

Flutter Web/мобильные клиенты из одного кода — разумный компромисс: web сейчас, iOS/Android позже без переписывания, при условии бюджета производительности (см. `h14`).

## Лучшие практики

- **Web-first для пилота**: мгновенная ссылка, OG-превью, состояние в URL, история, адаптив.
- **Системная «назад» везде**: web history, Telegram BackButton, predictive back.
- **Конвенции платформы**: HIG на iOS, Material на Android, web-привычки в браузере; не смешивать.
- **PWA по готовности**: manifest, иконки, офлайн-оболочка, своё предложение «добавить на экран» после ценности.
- **Mini App как канал**, если сообщество живёт в Telegram: вход из бота, уведомления через бота, тот же web-клиент внутри.
- **Совместимость версий** для нативных клиентов; принудительное обновление — только при угрозе.
- **Лёгкость**: бюджет производительности, адаптивные изображения, отложенная загрузка.
- **Копирование и шаринг** в один тап; Web Share API.
- **Системные шрифты и контролы** по умолчанию.
- **Планировать RuStore и прямой APK** для нативного на Android в РФ; оплату — через СБП/провайдера, не через стор.

## Признаки проблемы

Нативное приложение на пилот · ссылка из чата ведёт в стор · «назад» закрывает продукт · SPA без URL · iOS-шиты на Android · кастомный пикер даты · системный промпт «установить» на первом визите · невыделяемый текст · расчёт на Apple Pay в РФ.
