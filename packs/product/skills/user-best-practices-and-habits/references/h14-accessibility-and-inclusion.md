# H14. Доступность и разнообразие пользователей

> Треть людей увеличила системный шрифт, многие включили тёмную тему и уменьшение анимации, значительная доля сидит на среднем Android с нестабильной сетью, часть видит плохо, часть читает медленно, часть старше шестидесяти. Доступность — не для «особых пользователей», а для всех в неудобный момент: на солнце, одной рукой, в метро, с разбитым экраном.

Источники: WCAG 2.2 (2023), WebAIM Million 2025 (≈95 % сайтов с ошибками доступности; главные — контраст, подписи, alt), Apple/Google accessibility stats (значительная доля устройств с увеличенным шрифтом; на iOS заметная доля использует Dynamic Type выше дефолта), Microsoft Inclusive Design (постоянные, временные, ситуативные ограничения), ВОЗ (≈16 % населения с инвалидностью), Росстат (старение аудитории; старше 55 — быстрорастущий сегмент интернета), StatCounter 2026 (Android ≈ 2/3 мобильного трафика в РФ), Google (медленная сеть — главная причина отказа), NN/g для старших пользователей, ГОСТ Р 52872-2019, EAA (ЕС, 2025).

## Привычки и ограничения

| Привычка / ограничение | Что наблюдаем | Что это значит | Типичная ошибка |
|---|---|---|---|
| **Крупный системный шрифт** | Заметная доля (по разным оценкам до трети) увеличила шрифт в настройках | Текст масштабируется; макет не ломается при 150–200 %; размеры в относительных единицах | Фиксированные px, обрезанный текст |
| **Тёмная тема** | Значительная доля включает системную; ожидают, что продукт следует | Поддержка `prefers-color-scheme`; контраст в обеих | Только светлая |
| **Уменьшение анимации** | Включают при укачивании и для скорости | `prefers-reduced-motion`: без параллаксов и автоплея | Обязательные анимации |
| **Одной рукой, на ходу** | Большой палец, тряска, отвлечение | Цели ≥ 44×44 pt, главное внизу, крупные элементы, прощение промахов | Мелкие иконки вверху |
| **На солнце и в темноте** | Низкий контраст не читается | Контраст ≥ 4,5:1 для текста, ≥ 3:1 для крупного и UI | Серый на белом |
| **Средний Android и слабая сеть** | 2/3 трафика РФ; бюджетные устройства; 4G с провалами, метро | Бандл лёгкий, изображения сжаты, первый контент < 1 с, офлайн-терпимость | Тяжёлый веб-клиент, автоплей видео |
| **Старшие пользователи** | Медленнее читают, боятся ошибиться, не знают жестов, не любят мелкое; но платёжеспособны и лояльны | Явные кнопки вместо жестов, крупный текст, подтверждение важного, спокойный тон, нет жаргона | Скрытые жесты, «свайпните» |
| **Цветовое зрение** | ≈8 % мужчин с нарушением; красный/зелёный неразличимы | Цвет + иконка + текст для статусов; не только цвет | Ошибка только красной рамкой |
| **Скринридеры и клавиатура** | Незрячие, слабовидящие, моторные ограничения; также голосовое управление | Семантика: заголовки, подписи полей, alt, фокус, порядок, роли; без ловушек фокуса | Div-кнопки, картинки без alt |
| **Когнитивная нагрузка** | Усталость, тревога, дислексия, нет времени | Простые тексты, один шаг за раз, без таймеров, возможность вернуться | Таймер на форму, сложный текст |
| **Локаль: имена** | Имя одним словом, двойные фамилии, отчество, латиница | Одно поле «как к вам обращаться»; не валидировать «реальность» имени | Проверка имени по регулярке |
| **Локаль: обращение** | «Вы» по умолчанию для широкой аудитории; «ты» — для молодёжи и внутри сообществ | Выбор тона под аудиторию, единообразно | Смешение ты/вы |
| **Локаль: форматы** | Даты ДД.ММ.ГГГГ, телефон +7 (XXX) XXX-XX-XX, рубли с пробелом, 24-часовое время, неделя с понедельника | Системная локаль; форматирование через Intl | Американские форматы |
| **Локаль: язык** | Русский основной; английские слова в UI раздражают старших | Русский без англицизмов там, где есть слово; термины продукта по-русски | «Логин», «сабмит», «фича» в UI |
| **Гендер и нейтральность** | Формы прошедшего времени и обращения зависят от пола; не все хотят указывать | Нейтральные формулировки («Вы отправили», «Запрос отправлен»); пол не спрашивать без нужды | «Вы зарегистрировался» |
| **Клавиатура и голос** | На десктопе — Tab/Enter; на мобильном — диктовка | Полная клавиатурная навигация; голосовой ввод | Только мышь/тап |
| **Субтитры и расшифровка** | Видео без звука в транспорте; голосовые без текста | Субтитры, транскрипции | Голосовые без текста |

## Лучшие практики

- **WCAG 2.2 AA как планка**: контраст, масштабирование до 200 %, фокус, подписи, alt, цели 24×24 минимум (лучше 44), без таймеров без продления, без ловушек.
- **Относительные размеры и системные шрифты**; тест макета при 150 % и 200 %.
- **Три темы по системе**: светлая, тёмная, высокий контраст; тест контраста автоматом в CI.
- **Статусы тройным кодом**: цвет + иконка + текст.
- **Семантическая разметка**: настоящие кнопки и ссылки, заголовки по уровням, подписи полей связаны, роли и состояния, живые области для изменений (тосты, ошибки).
- **Порядок фокуса = порядок чтения**; видимый фокус; Escape закрывает модалки.
- **Бюджет производительности**: первый контент < 1 с на среднем Android по 4G; изображения адаптивные; шрифты системные или с `font-display: swap`; без автоплея.
- **Офлайн-терпимость** (см. `h5`).
- **Тексты**: короткие, активный залог, без жаргона; уровень чтения — восьмой класс; для старших — явные глаголы и подтверждения.
- **Жесты дублируются кнопками**; важное не только свайпом.
- **Локаль**: Intl для дат, чисел, валюты; телефон в любом формате; одно поле имени; нейтральные формулировки; единый тон обращения.
- **Проверка**: автоматические проверки (axe, Lighthouse), ручной проход со скринридером (VoiceOver/TalkBack) и с клавиатуры, тест на среднем Android, тест при 200 % шрифта.

## Вопросы для брейншторма

1. Как экран выглядит при 200 % шрифта, в тёмной теме, на солнце?
2. Сколько весит первый экран и за сколько открывается на среднем Android по 4G?
3. Можно ли пройти флоу одной рукой, не глядя на верхние углы?
4. Какие статусы переданы только цветом?
5. Работает ли флоу с клавиатуры и со скринридером? Есть ли подписи у всех полей и alt у картинок?
6. Есть ли таймеры, автоплей, обязательные анимации?
7. Поймёт ли человек 65 лет каждый текст и каждый жест?
8. Что произойдёт с именем «Жан-Клод», «Анна Мария», «Ли»?
9. Какой тон обращения и единообразен ли он?
10. Есть ли формулировки, зависящие от пола?

## Признаки проблемы

Фиксированный размер шрифта · серый текст на белом · ошибка только цветом · div вместо кнопки · действие только свайпом · бандл в несколько мегабайт на первом экране · автоплей видео · «Вы зарегистрировался» · имя по регулярке · только светлая тема.
