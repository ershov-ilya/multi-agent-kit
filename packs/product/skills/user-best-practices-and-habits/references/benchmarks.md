# Бенчмарки с источниками

Ориентиры, а не цели. Методики различаются (классическое и скользящее удержание, старт-к-отправке и просмотр-к-отправке форм, медиана и среднее); сравнивай только внутри одной методики. Год — год данных или публикации. При цитировании в RFC — со ссылкой на источник.

## Как пользоваться

1. Найди строку для своего шага; проверь методику.
2. Запиши норму в раздел «Пользователь» RFC с источником.
3. Поставь цель с обоснованием, почему выше или ниже нормы.
4. При расхождении с реальностью — ищи причину в привычках (`h1`–`h16`), не в «плохих пользователях».
5. Обновляй файл при появлении новых отчётов; старые строки помечай годом.
