# H12. Поиск и обнаружение

> Поиск — первое действие значительной части пользователей и последнее для остальных, когда навигация не помогла. Люди печатают как говорят, с опечатками, и после ChatGPT всё чаще задают вопросы целиком. Ноль результатов — не ответ, а тупик, из которого нужен выход.

Источники: NN/g search usability (2001–2024), Baymard e-commerce search (2024: большинство сайтов не справляются с синонимами и опечатками; пользователи не меняют запрос после неудачи, а уходят), Algolia/Elastic benchmarks (автодополнение повышает конверсию поиска), YouGov 2026 и NN/g о поиске с ИИ (вопросы на естественном языке, но для фактов возвращаются к классическому поиску), Google (голосовой поиск — заметная доля мобильных запросов), исследования zero-results.

## Привычки

| Привычка | Что наблюдаем | Что это значит | Типичная ошибка |
|---|---|---|---|
| **Поиск первым** | Часть идёт в поиск сразу, минуя разделы; особенно когда знают, что ищут | Поиск виден на первом экране, если объектов много | Поиск в меню |
| **Печатают как говорят** | «репетитор математика рядом недорого», «кто поможет с ремонтом» | Полнотекст с синонимами, морфологией (русские падежи), стоп-словами; семантический поиск для свободного текста | Точное совпадение подстроки |
| **Опечатки и раскладка** | «hgtnbnjh», «репититор» | Исправление опечаток, транслит и раскладка, «показаны результаты по …» | Ноль результатов на опечатку |
| **Вопросы целиком** (после ChatGPT) | «Кто в сообществе может помочь с переездом в Казань?» | Понимать вопрос как запрос; извлекать сущности; отвечать подборкой, не ошибкой | «Слишком длинный запрос» |
| **Автодополнение ожидается** | Подсказки после 2–3 символов, недавние, популярные | Подсказки с категориями, недавние запросы, исправление по ходу | Поле без подсказок |
| **Не переформулируют после неудачи** | Ноль результатов → уход, не второй запрос | Никогда не пустой экран: ослабить фильтры, предложить похожее, показать популярное, предложить «оставить запрос» | «Ничего не найдено» |
| **Результаты сканируют** | Заголовок, 1–2 признака, подсветка совпадения | Релевантный сниппет с подсветкой; почему найдено | Карточка без контекста совпадения |
| **Ожидают релевантность по умолчанию** | Сортировка — редко; первый результат должен быть лучшим | Ранжирование по релевантности + контекст пользователя; объяснение | Сортировка по дате |
| **Фильтры после поиска, не до** | Сначала ввели, потом сужают | Фильтры-чипсы над результатами с числами; не требовать выбора категории до поиска | Обязательная категория |
| **Недавние и сохранённые** | Повторяют свои запросы | Недавние запросы в пустом поле; сохранённый запрос с уведомлением о новом | Пустое поле при фокусе |
| **Голос** | В дороге и у старших — диктуют | Кнопка микрофона в поиске на мобильном; распознанное редактируется | Нет голосового ввода |
| **Обнаружение без запроса** | Не знают, что искать; ждут подборку «что есть» | Главная с подборкой и категориями для тех, кто не ищет | Пустая главная с поиском |
| **Доверие к поиску падает после одной неудачи** | Один плохой результат — «тут поиск не работает» | Качество первого экрана результатов важнее глубины | Много мусора в выдаче |

## Лучшие практики

- **Поле поиска** на главной с плейсхолдером-примером («репетитор по математике», «попутчик в горы»), микрофон на мобильном.
- **Автодополнение** после 2 символов: подсказки запросов, объектов, категорий; недавние; клавиатурная навигация на десктопе.
- **Толерантность**: опечатки (расстояние 1–2), раскладка, транслит, морфология русского, синонимы предметной области, стоп-слова.
- **Естественный язык**: извлечение сущностей (кто, где, когда, зачем) из вопроса; семантический поиск по описаниям; при неуверенности — уточняющий вопрос одной строкой или чипсы.
- **Ноль результатов — никогда**: «По запросу ничего точного, но вот похожее», ослабление фильтров с объяснением, популярное, «оставить запрос — сообщим, когда появится». Для сервисов «по запросу» ноль результатов — естественное состояние; его экран — главный.
- **Сниппет с подсветкой** и причиной совпадения; 2–3 признака.
- **Релевантность по умолчанию** с объяснением; фильтры чипсами с числами; применённые видны.
- **Сохранённый запрос** как объект: уведомление при новом совпадении; это и есть «запрос» в сервисах по запросу.
- **Пустое поле при фокусе**: недавние, популярные, примеры.
- **Аналитика поиска** (не процесс, а требование): запросы с нулём результатов и без клика — главный источник улучшений словаря.
- **Скорость**: результаты < 1 с; первые — мгновенно из кэша.

## Вопросы для брейншторма

1. Что увидит человек, напечатав запрос с опечаткой, в другой раскладке, в другом падеже?
2. Что произойдёт с вопросом целиком?
3. Что показываем при нуле результатов и есть ли выход «оставить запрос»?
4. Какие подсказки появляются после двух символов?
5. Почему первый результат первый, и видно ли это?
6. Какие фильтры нужны после поиска и есть ли числа у них?
7. Что в пустом поле при фокусе?
8. Есть ли голосовой ввод на мобильном?
9. Что видит тот, кто не знает, что искать?
10. Сколько миллисекунд до результатов?

## Признаки проблемы

«Ничего не найдено» · поиск по подстроке · ноль результатов на опечатку · обязательная категория до поиска · сортировка по дате по умолчанию · поле без подсказок · результаты без подсветки · вопрос целиком как ошибка · пустая главная с одним полем.
