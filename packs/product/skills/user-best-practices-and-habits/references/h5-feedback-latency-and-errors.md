# H5. Отклик, ожидание и ошибки

> Люди терпят ожидание и не терпят неизвестность. Спиннер без слов хуже, чем честные «ещё секунд десять». Модалка «Вы уверены?» не предотвращает ошибку, а приучает жать «Да». Ошибка, которая объясняет, что делать, удерживает; «что-то пошло не так» — теряет.

Источники: Nielsen response-time limits (0,1 / 1 / 10 с, 1993, подтверждено 2014), Doherty threshold (0,4 с), Google/SOASTA (вероятность отказа растёт на 32 % при 1→3 с загрузки мобильной страницы; 53 % уходят при > 3 с), NN/g progress indicators и skeleton screens, Luke W «Skeleton screens», Material/HIG guidance on undo и snackbars, NN/g error message guidelines (2024), исследования optimistic UI.

## Пороги

| Порог | Восприятие | Что показывать |
|---|---|---|
| **< 100 мс** | Мгновенно; причинно-следственная связь | Ничего, кроме смены состояния элемента (нажатие, переключение) |
| **100–400 мс** | Заметно, но в потоке | Микроанимация, состояние кнопки; без индикатора |
| **400 мс – 1 с** | Пауза; внимание ещё на задаче | Скелетон или лёгкий индикатор на месте контента; оптимистичный UI |
| **1–10 с** | Ожидание; нужна обратная связь | Прогресс с понятным смыслом («подбираем среди 37 участников»), оценка времени после 3 с |
| **> 10 с** | Внимание уходит; человек переключается | Явное сообщение, оценка, возможность уйти и получить уведомление; фоновая задача |
| **Загрузка экрана > 3 с на мобильном** | Половина уходит | Производительность как UX-требование; скелетон мгновенно |

## Привычки

| Привычка | Что наблюдаем | Что это значит | Типичная ошибка |
|---|---|---|---|
| **Повторное нажатие** при отсутствии отклика | Двойные отправки, дубли | Мгновенная смена состояния кнопки; идемпотентность на сервере | Кнопка без состояния «отправляется» |
| **Скелетон воспринимается быстрее спиннера** | Структура контента обещает, что сейчас появится | Скелетон на месте карточек; спиннер только для коротких и неструктурированных | Спиннер на весь экран |
| **Оптимистичный UI ожидается в соцдействиях** | Лайк, отметка, отправка сообщения — сразу, откат при ошибке | Показать результат сразу, синхронизировать в фоне, откатить с объяснением | Ждать ответа сервера на лайк |
| **Прогресс без смысла раздражает** | Полоска, которая «застыла на 90 %», хуже честного «ещё ~10 с» | Прогресс по реальным шагам или честная оценка; неопределённый — с текстом стадии | Фейковый прогресс |
| **Подтверждение жмут не глядя** | «Вы уверены?» → «Да» автоматически | Undo вместо подтверждения; подтверждение только для необратимого с описанием последствий | Модалка на удаление черновика |
| **Undo ожидается** | Удалил, передумал — хочет вернуть в течение секунд | Тост с «Отменить» 5–8 с; корзина для важного | Необратимое удаление по тапу |
| **Тост читают, если он по делу** | Короткий, внизу, с действием; исчезает сам | Тост для подтверждений с undo; не для ошибок, требующих действия | Ошибка в тосте, который исчез |
| **Текст ошибки ищут глазами у места ошибки** | Сводка сверху не связывается с полем | Ошибка рядом + фокус; общая ошибка — баннер с действием | «Произошла ошибка» внизу |
| **Винят себя, потом продукт** | После второй непонятной ошибки — уход | Текст: что случилось, что сделать, что уже сохранено | Код ошибки, стек, «неизвестная ошибка» |
| **Офлайн — норма в дороге** | Метро, лифт, плохая сеть; ожидают, что введённое не пропадёт и отправится позже | Очередь отправки, черновики, индикатор «нет сети» без паники, автоповтор | Потеря формы при обрыве |
| **Повтор хотят одной кнопкой** | «Повторить» у ошибки сети | Кнопка повтора с сохранённым вводом | Вернуть к началу |
| **Состояние системы хотят видеть** | Отправлено? Доставлено? Прочитано? Обрабатывается? | Явный статус объекта с временем и следующим шагом | Объект без статуса |
| **Частичный успех путает** | 3 из 5 отправлено — что с остальными? | Явно: что удалось, что нет, что делать | «Готово» при частичном сбое |

## Лучшие практики

- **Состояния кнопки**: обычная → нажата → отправляется (спиннер внутри, текст «Отправляем…», блок повторного нажатия) → успех → ошибка с повтором.
- **Скелетон** повторяет структуру будущего контента; появляется мгновенно; анимация мягкая.
- **Оптимистичный UI** для действий с низкой ценой ошибки; откат с тостом «Не удалось сохранить, повторить».
- **Прогресс с текстом стадии**: «Проверяем код…», «Подбираем…», «Почти готово» — стадии реальные.
- **Долгие операции в фон**: «Это займёт около минуты. Можно закрыть — сообщим, когда готово».
- **Undo по умолчанию** для удаления, архивации, отправки (отложенная отправка 5 с для необратимых сообщений).
- **Подтверждение только для необратимого**, с описанием последствий и глаголом на кнопке («Удалить профиль навсегда», не «ОК»).
- **Тексты ошибок**: человеческим языком, что случилось + что делать + что сохранено; без вины; с correlation id для поддержки мелким шрифтом.
- **Единый компонент ошибки** на уровне экрана (сеть, сервер, нет доступа, не найдено) с разными текстами и действиями.
- **Офлайн-режим**: баннер «Нет сети. Введённое сохраним и отправим», очередь, автоповтор, ручной повтор.
- **Статусы объектов** видны в списке и карточке: «Отправлено 2 ч назад · ждём ответа · обычно 1–3 дня».
- **Производительность как требование RFC**: первый контент < 1 с на среднем Android и 4G; размер бандла и изображений; предзагрузка следующего экрана.
- **Звук и вибрация** — только по явному выбору пользователя и для важных событий.

## Признаки проблемы

Спиннер на весь экран без текста · кнопка без состояния отправки · «Вы уверены?» на каждое действие · удаление без undo · «Что-то пошло не так» · ошибка в исчезающем тосте · потеря формы при обрыве сети · полоска прогресса, застывшая на 90 % · объект без статуса.
