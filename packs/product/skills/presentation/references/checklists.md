# Чеклисты проверки по этапам

Собраны из гайдов TED и TEDx, книг Anderson, Duarte, Reynolds, Gallo, рекомендаций Peyton Jones для научных докладов, критериев оценки Toastmasters, исследований Mayer и Alley. Используй по этапам; для быстрого ревью готовой текстовки — раздел 9 с баллами. Метка ✔ означает, что источник проверен, и не уравнивает его силу: «✔ TED» — рекомендация организатора, «✔ Mayer» или «✔ Alley» — рецензируемое исследование. Пункты без метки — консенсус практиков.

## 1. До начала: цель и аудитория

- [ ] Знаю точное время в минутах и формат (зал, онлайн, запись) ✔ TED.
- [ ] Знаю, кто в зале: что знают, что чувствуют, чего хотят, чего боятся, что решают.
- [ ] Ответ на «что мне с этого?» для слушателя есть и прозвучит в первую минуту.
- [ ] Сформулирована **сквозная мысль ≤ 15 слов** ✔ Anderson.
- [ ] Идея проходит тест TEDx: новая? интересная? фактична? Это идея, а не история и не список фактов ✔.
- [ ] Мой доклад — дар или просьба? Если просьба, переделать в дар ✔ Anderson.
- [ ] Что изменится в голове слушателя: было «…» → станет «…».
- [ ] Призыв к действию конкретный: что, когда, первый шаг.
- [ ] Решено, нужны ли слайды вообще ✔ TED.
- [ ] Для решений руководства: ответ и просьба написаны первыми (пирамида).
- [ ] Для питча: один вывод на слайд, вывод в заголовке ✔ YC.
- [ ] Права на изображения и источники фактов собраны заранее ✔ TEDx.

## 2. Структура

- [ ] Одна фраза ABT написана: «…И…, НО…, ПОЭТОМУ…».
- [ ] Заголовки-сообщения, прочитанные подряд, рассказывают историю (горизонтальная логика).
- [ ] У каждого такта один вывод; такты без вывода удалены.
- [ ] Структура подходит задаче: решение → ответ первым; действие → Монро; идея → спарклайн; изменение → Story Spine.
- [ ] Начало с того, что аудитория понимает, обычно с проблемы ✔ Peyton Jones.
- [ ] Нет агенды, биографии и извинений в начале ✔ TED.
- [ ] Доказательства идут от наименее к наиболее сильному; всё лишнее вырезано ✔ TEDx.
- [ ] Контраргументы учтены ✔ TEDx.
- [ ] Главное стоит в начале и в конце; слабое — в середине (позиция в ряду).
- [ ] Есть один спроектированный момент, который запомнят (STAR: драматизация, формула, визуал, история, цифра) ✔ Duarte.
- [ ] Смена активности (история, вопрос, демо, визуал) каждые несколько минут.
- [ ] Три главных пункта, не пять (Shu & Carlson ✔).
- [ ] Финал — не резюме и не питч ✔ TEDx; финал один из семи сильных (Anderson); готов и произносится после вопросов.
- [ ] Переходы между тактами написаны явно.

## 3. Текст

- [ ] Слов не больше: минуты × 110 (русский) или × 140 (английский) минус 10–15% на паузы и реакцию; посчитано скриптом, не на глаз.
- [ ] Первые 60 секунд и финал написаны дословно для заучивания ✔ Anderson.
- [ ] Предложения короткие, разговорный регистр «вы» и «мы» (персонализация Mayer ✔).
- [ ] Каждое число имеет источник и человеческий масштаб.
- [ ] Жаргон либо объяснён, либо убран; проклятие знания проверено на человеке вне темы.
- [ ] Сквозная мысль повторена трижды с вариацией.
- [ ] Правило трёх и контраст использованы в ключевых фразах.
- [ ] Юмор связан с мыслью; если не смешно, убрано ✔ Anderson.
- [ ] Паузы отмечены в тексте.
- [ ] Текст слайда не дублирует речь дословно (избыточность ✔ Mayer).
- [ ] Блок Q&A: 5 вероятных и 3 неприятных вопроса с ответами.
- [ ] Нет «исследования показывают» без названия исследования (Goldberg).

## 4. Слайды

- [ ] Один тезис на слайд; слайды без назначения удалены ✔ TED.
- [ ] Тест трёх секунд пройден ✔ Duarte.
- [ ] Заголовок — утверждение, тело — доказательство (assertion-evidence ✔ Alley).
- [ ] Не больше 1–2 строк текста; нет слайдов «заголовок + буллеты» ✔ TED.
- [ ] Шрифт читается с последнего ряда: TEDx от 42 пунктов, Anderson от 24, питч 30 ✔; онлайн от 24–28.
- [ ] Не больше двух гарнитур и трёх размеров; один цвет текста плюс акцент ✔ Anderson.
- [ ] Контраст 4,5:1 для текста, 3:1 для крупного и графики ✔ WCAG.
- [ ] Смысл не кодирован только красным и зелёным.
- [ ] Картинки высокого разрешения, одна сильная, без клипарта и декоративного стока ✔ TED.
- [ ] Графики: одна мысль, заголовок-вывод, одна выделенная серия, подписи на данных, без сетки (Knaflic).
- [ ] Почти нет анимаций и переходов ✔ Anderson; постепенное появление только по смыслу.
- [ ] Видео не длиннее 30–60 секунд ✔; никакого видео в финале ✔.
- [ ] 16:9, 1920×1080, безопасные поля; проверено на 4:3, если площадка требует ✔ TEDx.
- [ ] Права на изображения; CC с подписью ✔ TEDx.
- [ ] Alt-текст, порядок чтения; отдельная раздатка вместо слайдумента.
- [ ] В питче нет оглавления, есть слайд про конкурентов, продукт и «почему сейчас» раньше ✔ DocSend.
- [ ] Запасные слайды под ожидаемые вопросы в приложении.

## 5. Репетиция

- [ ] Начата, как только появился черновик; недели, не дни ✔ TED.
- [ ] Вслух, стоя, по таймеру, с записью ✔ Duarte.
- [ ] Цикл: записал → расшифровал → отредактировал → повторил ✔ TED.
- [ ] Хотя бы раз перед людьми; чем больше слушателей, тем лучше (Smith & Frymier ✔).
- [ ] Получена честная обратная связь по вопросам Anderson: контакт глазами? новая идея построена? юмор естественный? визуал помогал? звучал как декламация? разговорно или проповедь? разнообразие тона и темпа? ✔
- [ ] Хронометраж с запасом 10% под лимит ✔.
- [ ] Помечено, что резать при нехватке времени; финал не режется.
- [ ] Стоя на месте; кликер отрепетирован ✔ TED.
- [ ] Долина неловкости пройдена: либо выучено до естественности, либо говорю по пунктам ✔ Anderson.
- [ ] Перерыв 1–2 недели для свежего взгляда (если есть время) ✔ TED.
- [ ] Генеральная на площадке с микрофоном, кликером, монитором, входом и выходом ✔ TEDx.
- [ ] Демо: точный путь отрепетирован, видеозапись и второе устройство готовы ✔ Vogelstein.
- [ ] Посчитаны слова-паразиты в записи; план их замены паузами.

## 7. Во время

- [ ] Пауза, вдох, ноги на месте, затем первое слово ✔ TED.
- [ ] Тон «как история за ужином» ✔ TED.
- [ ] Взгляд на людей, по одному до конца мысли; онлайн — в объектив.
- [ ] Жесты открытые и иллюстрирующие содержание (Cascio Rizzo 2025 ✔); движение только с целью.
- [ ] Не читать слайды, не поворачиваться к экрану.
- [ ] Паузы вместо заполнителей; пауза перед ключевой фразой и после.
- [ ] Часы под контролем; резать помеченное; финал не трогать.
- [ ] Q&A: повторить вопрос, ответить, вернуться к мысли; «не знаю, выясню»; затем заготовленный финал.

## 9. Экспресс-ревью текстовки: 20 вопросов с баллами

Ставь 0, 1 или 2 за каждый: **0** — нет или неверно; **1** — есть, но частично или слабо; **2** — есть и работает. Вопросы 10, 14 и 19 оцениваются только когда факты подтверждены, темп измерен и финал отрепетирован; до этого ставь «н/о» и считай порог от оставшихся. 32+ из 40 — готово к репетиции; 24–31 — доработать помеченное; меньше 24 — вернуться к структуре. Баллы оценивают текст, не готовность спикера.

## 10. Красные флаги: если есть хоть один, останавливаемся

- Не могу сформулировать сквозную мысль одной фразой.
- Доклад о нас, а не о проблеме слушателя.
- Больше одной главной идеи.
- Слайды с буллетами, которые читаются вслух.
- Финал «ну вот и всё» или «есть вопросы?».
- Хронометраж не проверен вслух.
- Факт или цифра без источника.
- Наполовину выученный текст за день до выступления.
- Демо без запасного варианта.
- Продажа, логотипы, сбор денег на идейном выступлении ✔ TED.
