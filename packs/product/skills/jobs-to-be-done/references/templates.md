# Шаблоны и канвасы

> Заполняемые формы на русском для сессий и исследований. Копируй блок целиком и заполняй; поля с «…» обязательны, в скобках — подсказки. Терминология совпадает с остальными файлами скилла.

## 1. Карточка работы

```
## Работа: <короткое имя>
Исполнитель (роль в момент работы, не должность): …
Обстоятельства (когда, где, что только что произошло): …
Главная функциональная работа (глагол + объект + контекст, без решения): …
Уровень выше (зачем): …
Уровень ниже (как, 2–4 подработы): …
Эмоциональная сторона (хочу чувствовать / не чувствовать): …
Социальная сторона (хочу выглядеть / не выглядеть): …
Job story: Когда …, я хочу …, чтобы …
Критерий «работа выполнена»: …
Текущие решения (включая «ничего» и самоделку): …
Частота работы: … раз в <день / неделю / месяц / год>
Кто платит, кто решает, кто влияет: …
Источник (интервью N / данные / отзывы / гипотеза): …
Уверенность (высокая: интервью с исполнителями / средняя: существующие исследования / низкая: экспертиза): …
```

## 3. Диаграмма сил

```
## Силы: <работа / сегмент>

PUSH (толчок ситуации)                        │ ТРЕВОГА (перед новым)

 2. …                                          │  2. …
 3. …                                          │  3. …
PULL (притяжение нового)                       │ ПРИВЫЧКА (к старому)
 1. …                                          │  1. …
 2. …                                          │  2. …
 3. …                                          │  3. …
Главная сила в каждой ячейке: push … | pull … | тревога … | привычка …
Что делает продукт с каждой: …
Что делает лендинг с каждой: …
```

## 5. Сценарий switch-интервью (45–60 минут)

```
## Рекрут
Событие: купили / переключились / отказались / ушли за последние 30–90 дней
Сегмент: …
Количество: 6–12
Вознаграждение: …

## Установка (2 мин)
«Я хочу восстановить, как всё было, шаг за шагом, как в документальном фильме.
Нет правильных ответов. Важны скучные детали. Названия продуктов и фич не обсуждаем.»

## Покупка / решение (10 мин)
- Когда и как вы купили (подписались, установили)? Где были, какой день, кто рядом?
- Что сравнивали в последний момент? Почему именно тогда?
- Что чуть не остановило?

## Активный поиск (10 мин)
- Когда стали искать всерьёз? Что случилось?
- Что смотрели, кого спрашивали, в каком порядке?
- По каким признакам отбрасывали варианты?

## Первая мысль и старое решение (15 мин)
- Когда впервые подумали, что так дальше нельзя? Что происходило?
- Что использовали до этого? Что в нём было хорошо?
- Что стало невыносимым? Конкретный случай.
- Что потеряли при переходе? Что сохранили?

## Использование (10 мин)
- Расскажите про первый раз. Что получилось, что нет?
- Когда в последний раз обращались? Зачем?
- Что теперь делаете по-другому? Что перестали?

## В конце (5 мин)
- Если бы продукта не было, что бы делали?
- Как объяснили бы другу, зачем это?

## Разметка после интервью
Таймлайн с датами: …
Силы с цитатами: push … | pull … | тревога … | привычка …
Критерии выбора: … Компромиссы: …
Кандидаты в работы: …
```

## 7. Анкета ODI (фрагмент)

```
Вступление: «Вспомните, как вы в последний раз <работа>. Оцените каждое утверждение по двум шкалам.»

Для каждого результата:
«<Минимизировать время, которое требуется, чтобы …>»
Насколько это важно для вас?        1 — совсем не важно … 5 — крайне важно
Насколько вы удовлетворены тем,
как это получается сейчас?           1 — совсем не удовлетворён … 5 — полностью удовлетворён

Блок сегментации:
- Как часто вы <работа>? (ежедневно / еженедельно / ежемесячно / реже)
- Чем пользуетесь сейчас? (список + «своё решение» + «ничего»)
- Ваша роль в момент работы: …
- Кто принимает решение об инструменте: вы / руководитель / другое
Объём: 30–60 результатов за проход; при 100+ — ротация блоков.
```

## 12. Повестка воркшопа (90 минут)

```
00:00 Контекст и данные под рукой (10) — ведущий
00:10 Работа на трёх уровнях, три стороны, чеклист (20) — все, запрет на названия продуктов
00:30 Карта работы: восемь шагов, где болит (20) — в парах по шагам
00:50 Силы и таймлайн (15) — по одной главной силе в ячейке
01:05 Конкуренты через работу (10)
01:15 Решения: строим / не строим / говорим / мерим (10)
01:25 План проверки и отклонённые идеи (5)
Артефакты: карточка работы, карта, диаграмма сил, список решений, план проверки.
```

## 13. Отчёт исследования (структура)

```
1. Вопрос исследования и гипотезы до поля
2. Метод: кого, сколько, как рекрутировали, окно
3. Работы (с уровнями, сторонами, частотой упоминания)
4. Силы (частоты, цитаты)
5. Таймлайн (типичные события-домино)
6. Карта работы и разрывы (если проводили ODI — opportunity)
7. Конкуренты через работу
8. Следствия: продукт, онбординг, лендинг, прайсинг, метрики
9. Что подтвердилось и что опровергнуто из гипотез
10. Границы исследования и следующий шаг
```
