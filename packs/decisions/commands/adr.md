# Фиксация решений

Канон процесса — раздел «Процесс RFC, ADR и OPS» в `AGENTS.md`. Каталог: `{{mak.decisions}}`.
Перед фиксацией прочитай канон и релевантные решения.

Вызывай, когда есть осознанный результат: смена подхода, выкладка, разбор инцидента. Не на каждую
правку опечатки. Если итог — только мелкий урок без сдвига архитектуры, дополни OPS к существующему
ADR, новый ADR не создавай. Черновик на обсуждение — RFC со статусом `draft`, не ADR.

1. Создай документ: `{{mak.cli}} decisions create TYPE scope topic`.
2. Заполни разделы: контекст, решение или опыт, последствия. Кратко, без секретов.
3. Если решение заменяет старое — в новом `supersedes`, у старого статус `superseded` и ссылка
   на новый. Старые файлы не удаляй.
4. Обнови индекс: `{{mak.cli}} decisions index`.

Не создавай коммит без явной просьбы пользователя. В отчёте — пути новых файлов, что заменено,
что отложено.
